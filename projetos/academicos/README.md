### Exercícios de SQL

- **Tecnologias:** SQL e modelagem de dados;

## Padrão de documentação

Cada novo projeto deve possuir um diretório próprio e um `README.md` contendo objetivo, tecnologias, instruções de execução, aprendizados e status.
