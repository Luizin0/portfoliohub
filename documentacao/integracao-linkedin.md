# Integração com o LinkedIn

## Como adicionar este projeto ao perfil

1. Acesse o perfil no LinkedIn;
2. Clique em **Adicionar seção do perfil**;
3. Escolha **Recomendado > Adicionar projetos** ou **Destaques**;
4. Use o título **PortfólioHub - Portfólio acadêmico e pessoal**;
5. Informe a URL `https://luizin0.github.io/portfoliohub/`;
6. Adicione a descrição abaixo.

## Descrição sugerida

> Portfólio desenvolvido com HTML, CSS e JavaScript para organizar e apresentar meus projetos acadêmicos e pessoais. O repositório utiliza Git para controle de versão, documentação em Markdown e GitHub Pages para publicação.

## Publicação sugerida

> Publiquei a primeira versão do meu PortfólioHub! O projeto reúne minha trajetória acadêmica, competências e projetos, com organização, documentação e versionamento no GitHub. Acesse: https://luizin0.github.io/portfoliohub/

Antes de publicar, confirme se o GitHub Pages já está acessível.
