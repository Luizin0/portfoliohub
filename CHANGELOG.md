# Histórico de versões

Todas as alterações relevantes deste projeto serão registradas neste arquivo.

## [1.1.0] - 2026-10-26

- Integração com a API pública do GitHub e tratamento de falhas.
- Área com plano no Google Documentos, segurança, contribuição e download do código.
- Políticas de acesso, arquivo de exclusão de segredos e guia de colaboração.
- Testes automatizados e verificação em pull requests e na main.
- Foco visível, suporte a Escape e ajustes para telas pequenas.

## [1.0.0] - 2026-10-17

### Adicionado

- Página inicial responsiva do portfólio;
- Seções de apresentação, projetos e competências;
- Estrutura de projetos acadêmicos e pessoais;
- Documentação de planejamento, LinkedIn e apresentação;
- Acessibilidade básica, menu móvel e animações com preferência de movimento reduzido;
- Configuração compatível com GitHub Pages.
